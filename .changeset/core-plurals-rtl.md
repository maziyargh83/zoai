Plurals (`{ one, other }` with `count`), fallback locale, number placeholders with optional locale formatting, `{{ spaced }}` placeholders, `has()`, `subscribe()`, `dir()`, `formatNumber()`, `getDirection()` and `matchLocale()`. Keys must now exist in every locale and point to a translation (not a nested object). The default export is now exposed from the package entry.
